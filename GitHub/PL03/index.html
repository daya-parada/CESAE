HTML
HTML é a abreviatura de Hypertext Markup Language, ou seja, Linguagem de Marcação de Hipertexto. É uma notação usada para a publicação de conteúdo (texto, imagens, vídeos, áudio, …) na web.
CSS
CSS é a abreviatura de Cascading Style Sheets, ou seja, Folhas de Estilo em Cascatas. É uma linguagem de estilo utilizada para definir a apresentação de elementos HTML.
